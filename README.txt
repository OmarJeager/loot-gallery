N • ASSET GALLERY — OFFLINE HTML/CSS/JAVASCRIPT

WHAT IT DOES
- Browse images under C:\Eren\N, including Assembly and Cutting and their nested folders.
- Filter by main folder and subfolder.
- Search image names (examples: g54644, j4648674, 45545547).
- Grid/list view, image preview lightbox, sorting, dark/light mode, English/French/Arabic translations.
- Runs locally in your browser. It does not upload images or use a server.

IMPORTANT BROWSER LIMITATION
A normal HTML page cannot silently read C:\Eren\N due to browser security. You select the folder yourself each time using the folder picker. This is expected and keeps access under your control.

HOW TO USE
1. Extract the ZIP anywhere, for example C:\Eren\FolderGallery.
2. Open index.html in Chrome or Microsoft Edge.
3. Click “Select folder”.
4. In the folder picker, browse to C:\Eren and select the N folder (then click “Select Folder” / “Select”).
5. Choose Assembly or Cutting in the first dropdown.
6. Choose a subfolder in the second dropdown, or keep “All subfolders”.
7. Search by image filename in the search box. Click an image to preview it.
8. Use the top controls to switch language or dark/light mode.

FOLDER EXAMPLE
C:\Eren\N\
  Assembly\
    folder-A\
      g54644.jpg
    folder-B\
      45545547.png
  Cutting\
    folder-C\
      j4648674.jpeg

SUPPORTED IMAGE TYPES
AVIF, BMP, GIF, JPG/JPEG, PNG, SVG, TIFF, WEBP.

NOTES
- Keep the folder structure intact.
- For very large libraries, the initial folder selection can take a moment because the browser indexes the selected files.
- The app works without internet. If you move the folders to another PC, copy this app and select the new location's N folder.
- The app does not modify or delete your original files.
